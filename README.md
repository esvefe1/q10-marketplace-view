# Marketplace de Aplicaciones – Prueba Técnica Q10

Este proyecto es una prueba técnica desarrollada para la empresa **Q10**, con el objetivo de implementar un **marketplace de aplicaciones** utilizando tecnologías modernas como Next.js y Sass.

## 🧪 Tecnologías utilizadas

- ⚙️ **Next.js** – Framework de React para aplicaciones web modernas.
- 🎨 **Sass** – Preprocesador CSS para estilos más organizados y mantenibles.
- ☁️ **Vercel** – Plataforma de despliegue utilizada para producción.
- 🔧 **nvm** – Manejo de versiones de Node.js (recomendado usar la versión 20.x).
- 📦 **Yarn** – Gestor de paquetes.
